# 🌱 Agro Forte, Futuro Sustentável

Projeto de página inicial desenvolvido para o Concurso de Programação com o tema:

> **“Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente”**

O concurso é promovido pelo Serviço Nacional de Aprendizagem Rural do Paraná (SENAR-PR) e pela Secretaria de Estado da Educação do Paraná (SEED-PR).

---

# 📖 Sobre o Projeto

Este projeto consiste em uma landing page moderna e responsiva voltada para a divulgação do concurso.

A página apresenta:

- Banner principal com destaque para o tema
- Seção explicativa sobre sustentabilidade e tecnologia
- Cards com os objetivos do concurso
- Área dos organizadores
- Design moderno e responsivo

---

# 🎯 Objetivo

O objetivo do site é incentivar:

- Sustentabilidade no agronegócio
- Uso de tecnologia no campo
- Preservação ambiental
- Inovação através da programação

---

# 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- Google Fonts
- Design Responsivo
